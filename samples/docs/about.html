Force-Displacement File Format

The first row of each force-displacement file contains the test name, and the second row contains the number of force-displacement pairs in the history. From the third row onwards, the force-displacement pairs are provided in adjacent columns. The first column contains the top-displacement values (in mm), and the second column contains the lateral-load values (in kN). Regardless of the actual test geometry, all force-displacement data are reported in terms of an equivalent cantilever column.

Nv Number of transverse shear bars in cross section
Configuration C : Cantilever
DC : Double Cantilever
DE : Double Ended
Type of Confinement (Code) (1) I: Interlocking ties
(2) R: Rectangular ties (around perimeter)
(3) RD: Rectangular and Diagonal ties
(4) RI: Rectangular and Interlocking ties
(5) RIJ: Rectangular and Interlocking ties, with J-hooks
(6) RJ: Rectangular ties with J-hooks
